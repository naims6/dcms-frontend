## ✨ Features & Highlights

<table>
  <tr>
    <td width="50%">
      <h3>🌐 Multi-Language Localization</h3>
      <p>Seamlessly localized and internationalized using <code>next-intl</code> to support dual/multiple language translation for dynamic switching.</p>
    </td>
    <td width="50%">
      <h3>🔒 Secure, Dynamic Forms</h3>
      <p>Integrated with <code>React Hook Form</code> and backed by strict <code>Zod</code> schemas to ensure robust, typed client-side validation.</p>
    </td>
  </tr>
  <tr>
    <td width="50%">
      <h3>🌓 System-Adaptive Theme</h3>
      <p>Automatic dark/light mode switches, tailored seamlessly to user system preferences with custom transition curves.</p>
    </td>
    <td width="50%">
      <h3>📱 Fully Responsive Layout</h3>
      <p>Fluid grids and flexboxes built mobile-first to look stunning and premium on devices of all screen sizes.</p>
    </td>
  </tr>
</table>
